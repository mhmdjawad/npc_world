🌍 NPC World

Deterministic Tick-Based Simulation

Welcome to NPC World, a real-time simulation environment where NPCs live, interact, and evolve in a deterministic world. Watch entities move, observe their behaviors, and interact through our REST API and WebSocket connections.

Features

  • Deterministic tick-based simulation with seeded PRNG
  • Real-time entity tracking via WebSocket
  • REST API for world and entity management
  • MySQL database for persistent storage
  • Docker Compose for easy deployment
  • Player registration and entity assignment
  • Idea system for entity goals and behaviors
